# 🌟 Awesome Patent Analytics 🌟

**A Curated List of SaaS Products & Open-Source GitHub Projects for Patent Intelligence.** 🚀  
*Focused on Patent Search, Landscape Analysis, Competitive Intelligence, Citation Networks & IP Strategy*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Patent Analytics**. These tools enable searching global patent databases, performing landscape and competitive analysis, citation mapping, technology scouting, freedom-to-operate (FTO) assessments, portfolio valuation, and strategic IP decision-making. 💡

**Examples** include PatSnap, LexisNexis PatentSight, Derwent Innovation, IFI Claims, Gridlogics, Questel Orbit, Ambercite, Cipher, IP.com, and Google Patents Public Datasets (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project, open data sources, analytics toolkits, and free platforms for patent search and analysis — ideal for researchers, startups, IP professionals, and organizations seeking transparent, low-cost, or fully controllable patent intelligence capabilities. 🌍

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## 💻 Open-Source GitHub Projects

Here are some of the most popular open-source projects for patent analytics, sorted by GitHub Stars ⭐.

- **[google/patents-public-data](https://github.com/google/patents-public-data)** [![GitHub Stars](https://img.shields.io/github/stars/google/patents-public-data?style=social&color=white)](https://github.com/google/patents-public-data/stargazers)  
  Open models, datasets, and utilities related to Google’s public patent corpus and patent-specific language models.

- **[Lens.org](https://www.lens.org/)** *(Platform with Open APIs)*  
  Leading free/open platform for global patent and scholarly search, analytics, citation mapping, and data export.

- **[wipo-analytics/wipo-analytics](https://github.com/wipo-analytics/wipo-analytics)** [![GitHub Stars](https://img.shields.io/github/stars/wipo-analytics/wipo-analytics?style=social&color=white)](https://github.com/wipo-analytics/wipo-analytics/stargazers)  
  Practical guides, scripts, and resources from WIPO for performing patent analytics with free and open-source tools.

- **[PatentsView-API (USPTO)](https://github.com/PatentsView/PatentsView-API)** [![GitHub Stars](https://img.shields.io/github/stars/PatentsView/PatentsView-API?style=social&color=white)](https://github.com/PatentsView/PatentsView-API/stargazers)  
  USPTO-supported open data APIs providing structured U.S. patent data, disambiguation tools, and research-ready datasets for analytics.

- **[Patent2net/P2N-v3](https://github.com/Patent2net/P2N-v3)** [![GitHub Stars](https://img.shields.io/github/stars/Patent2net/P2N-v3?style=social&color=white)](https://github.com/Patent2net/P2N-v3/stargazers)  
  Open-source patent analytics toolkit for collecting, processing, statistical analysis, and visualization of patent data.

- **[pqaidevteam/pqai](https://github.com/pqaidevteam/pqai)** [![GitHub Stars](https://img.shields.io/github/stars/pqaidevteam/pqai?style=social&color=white)](https://github.com/pqaidevteam/pqai/stargazers)  
  Open-source semantic prior-art search engine using dense neural retrieval over large patent corpora.

- **[ip-tools/patzilla](https://github.com/ip-tools/patzilla)** [![GitHub Stars](https://img.shields.io/github/stars/ip-tools/patzilla?style=social&color=white)](https://github.com/ip-tools/patzilla/stargazers)  
  Modular open-source toolkit and platform components for accessing and integrating patent data from multiple sources.

- **[KonstantinosPetrakis/PatentInspector](https://github.com/KonstantinosPetrakis/PatentInspector)** [![GitHub Stars](https://img.shields.io/github/stars/KonstantinosPetrakis/PatentInspector?style=social&color=white)](https://github.com/KonstantinosPetrakis/PatentInspector/stargazers)  
  Open-source web application for analyzing patent data with a focus on usability, built with Django and Vue.

- **[ropensci/patentsview](https://github.com/ropensci/patentsview)** [![GitHub Stars](https://img.shields.io/github/stars/ropensci/patentsview?style=social&color=white)](https://github.com/ropensci/patentsview/stargazers)  
  Open-source R client for querying PatentsView APIs programmatically.

- **[USPTO/OpenData](https://github.com/USPTO/OpenData)** [![GitHub Stars](https://img.shields.io/github/stars/USPTO/OpenData?style=social&color=white)](https://github.com/USPTO/OpenData/stargazers)  
  Community and official libraries for accessing USPTO bulk data, APIs, and public patent information programmatically.

### Additional Strong Open-Source Options 🛠️

- **Open data sources**: Google Patents Public Datasets (BigQuery), PatentsView bulk data, Lens.org APIs, USPTO bulk downloads, EPO Open Patent Services.
- **Citation & network analysis**: Graph libraries (NetworkX, igraph) combined with open patent citation data.
- **Text mining & NLP**: spaCy, Hugging Face models fine-tuned on patents, and open patent embedding projects.
