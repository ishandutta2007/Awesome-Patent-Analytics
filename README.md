# Awesome-Patent-Analytics

## Top Patent Analytics Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Patent Search, Landscape Analysis, Competitive Intelligence, Citation Networks & IP Strategy*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Patent Analytics**. These tools enable searching global patent databases, performing landscape and competitive analysis, citation mapping, technology scouting, freedom-to-operate (FTO) assessments, portfolio valuation, and strategic IP decision-making.

**Examples** include PatSnap, LexisNexis PatentSight, Derwent Innovation, IFI Claims, Gridlogics, Questel Orbit, Ambercite, Cipher, IP.com, and Google Patents Public Datasets (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project, open data sources, analytics toolkits, and free platforms for patent search and analysis — ideal for researchers, startups, IP professionals, and organizations seeking transparent, low-cost, or fully controllable patent intelligence capabilities.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[Lens.org](https://www.lens.org/)**  
  Leading free/open platform for global patent and scholarly search, analytics, citation mapping, and data export — widely regarded as the strongest open alternative for professional use.

- **[PatentsView](https://github.com/PatentsView)**  
  USPTO-supported open data platform and APIs providing structured U.S. patent data, disambiguation tools, and research-ready datasets for analytics.

- **[Patent2Net (P2N)](https://github.com/Patent2net/P2N-v3)**  
  Open-source patent analytics toolkit for collecting, processing, statistical analysis, and visualization of patent data, aimed at academic and low-resource users.

- **[PQAI (Project PQAI)](https://github.com/pqaidevteam)**  
  Open-source semantic prior-art search engine using dense neural retrieval over large patent corpora for AI-assisted patent quality and novelty analysis.

- **[WIPO Open Source Patent Analytics Manual & Tools](https://github.com/wipo-analytics)**  
  Practical guides, scripts, and resources from WIPO for performing patent analytics with free and open-source tools.

- **[PatZilla / IP-Tools](https://github.com/ip-tools)**  
  Modular open-source toolkit and platform components for accessing and integrating patent data from multiple sources.

- **[Google Patents Public Data Tools & BERT for Patents](https://github.com/google)**  
  Open models, datasets, and utilities related to Google’s public patent corpus and patent-specific language models.

- **[PatentInspector](https://github.com/KonstantinosPetrakis/PatentInspector)**  
  Open-source web application for analyzing patent data with a focus on usability, built with Django and Vue.

- **[USPTO Open Data Python Clients & Utilities](https://github.com/USPTO)**  
  Community and official libraries for accessing USPTO bulk data, APIs, and public patent information programmatically.

- **[R and Python Patent Analytics Packages](https://github.com/ropensci/patentsview)**  
  Open-source clients (e.g., patentsview R package) and scripts for querying PatentsView, Lens, and other open patent APIs.

- **[Espacenet & OPS-related Open Tools](https://github.com/ip-tools)**  
  Community libraries and wrappers for accessing European Patent Office data and Open Patent Services.

- **[Open Patent Analytics Notebooks & Pipelines](https://github.com/wipo-analytics)**  
  Collections of Jupyter notebooks and reproducible workflows for cleaning, analyzing, and visualizing patent datasets.

### Additional Strong Open-Source Options

- **Open data sources**: Google Patents Public Datasets (BigQuery), PatentsView bulk data, Lens.org APIs, USPTO bulk downloads, EPO Open Patent Services.
- **Citation & network analysis**: Graph libraries (NetworkX, igraph) combined with open patent citation data.
- **Text mining & NLP**: spaCy, Hugging Face models fine-tuned on patents, and open patent embedding projects.
- **Visualization**: Observable, Observable Plot, or open dashboard stacks built on patent data extracts.
- Many academic and community **patent landscaping scripts**, **CPC/IPC classifiers**, and **prior-art retrieval** prototypes on GitHub.

**Frameworks for building custom systems**: Combine **Lens.org or PatentsView APIs** for data access, **Google Patents Public Datasets** for large-scale querying, open NLP and graph libraries for analysis, and tools like **Patent2Net** or custom Jupyter pipelines to create a complete open-source patent analytics environment.
